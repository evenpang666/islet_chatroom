# 100 位预设人物的独立 Skill

每份文件独立维护十一个方面，含生活年份区间、知识与时代习惯、每日行动、偶发行动和三条原创语气示例。日程和语气是角色创作约束，历史资料、原著内容与聊天室新增经历需区分。模型只读取本角色的文件，用户定制优先于默认设定。

影视类采用原创影视或漫画改编的银幕版本，不收小说翻拍人物；例如托尼采用漫威电影宇宙版本，哈利仍属于小说类。虚构地点以可编辑的地球地点和时区安排生活，这只是作息锚点，不是现实住址。

## 年代的使用方式

历史人物记录生命区间，并继续服从各自的人生阶段；故事人物采用对应作品和版本的活动范围。原作没有确年时，明确写成宽年代参照；虚构历法不硬换公元纪年。每份都说明可知范围与适用的日常工具，不能把网页现实年份当成角色已活到今天。用户明确改写优先，后世知识可以在群聊中学习，但不能冒充旧日亲历。

部分年代与世界背景参考：[诺贝尔奖爱因斯坦资料](https://www.nobelprize.org/prizes/physics/1921/einstein/facts/)、[诺贝尔奖爱因斯坦传记](https://www.nobelprize.org/prizes/physics/1921/einstein/biographical/)、[皮克斯瓦力介绍](https://www.pixar.com/wall-e)、[星际迷航系列介绍](https://www.startrek.com/series/star-trek-the-next-generation)。这些资料不为本项目的推算区间、创作日程和原创发言背书；具体限制写在各人物的“生活年代”章节。
