## 人物设定与 Skill

每个角色有独立的持久化 DSH 会话、记忆列表和专属 Skill。

- 通用约束：[skills/SKILL.md](../skills/SKILL.md)。
- 100 份预设人物约束：[人物索引](../skills/characters/README.md)，文件位于 `skills/characters/chatroom-<人物ID>/SKILL.md`。
- 群内专属 Skill：开始聚会时，将所选预设、用户定制资料和实际作息合成为该角色的文件。全部角色准备完毕后才统一加入。

每份预设覆盖背景、生活年代、性格动机、语言、生活习惯、每日行动、偶发行动、群聊互动、关系与记忆、演绎边界，以及三条原创语气示例。内敛与活泼人物有不同的默认节奏，均可编辑。历史人物、小说角色和影视人物都是 AI 演绎，不能视为真人或原著原话。

人物分为小说角色 35 位、影视人物 25 位、科学家 17 位、文学家 23 位。影视类采用电影或剧集版本，包括原创影视及漫画改编银幕角色（如托尼·斯塔克），不包含小说翻拍人物；哈利·波特等仍归小说类。同名人物不混合漫画、电影、重启版与演员的私人经历。

用户确认的背景、性格、风格、习惯与地点优先于预设默认值。原创人物只使用通用约束和自己的资料。重启时会重建角色 Skill，保留消息、记忆、自定义设定与外观。

DSH 宿主管理模型与凭据。专用角色 preset 提供完整 persona，禁用工具。每轮传入本角色的 Skill、个人记忆和最近 50 条群聊，不读取其他角色的私有记忆。每 24 轮轮换一次 DSH 会话，个人记忆和最近群聊继续保留。

## 角色占用与移出

同一角色只能加入一个未解散的聊天室，同一群内也不能重复选择。暂停群聊、用户暂时退出、修改角色名字或外观，都不释放占用。选择器会禁用已加入其他群的角色并注明群名，其他设备的变化实时同步；后台在创建时再次检查，并对同时到达的邀请统一排序。

预设人物用预设 ID 识别；原创人物有稳定的角色 ID，改名仍视为同一个人。分别创建的同名原创人物是不同角色，不按姓名合并。尚未开始的定制草稿仅在当前草稿内防重复，不占用全局角色池。

邀请方式：在群内侧栏、成员列表或设置中点击“邀请新朋友”，选择预设、创建原创人物或从文字提炼，完成定制后立即加入当前群。每群仍最多 5 位，满员后先移出一位；全局占用规则与竞争邀请检查继续生效，原有消息、用量和成员记忆保留。暂停时也能邀请，但角色要等聚会继续后才活动。

移出方式：进入群聊，点击人物头像，在详情底部选择“移出这位朋友”。移出会取消该人物未发送的回复，保留已有聊天，将人物资料、私有记忆和会话引用存入本群本地 `removedAgents` 归档；其余角色继续活动。角色随后可重新选择，新群使用独立会话与记忆，不自动带入旧群私有内容。最后一位被移出后，空群仍保留，可查看消息、留言、邀请新成员或解散。

新邀请与移出操作会追加灰色群聊系统提示，保存、导出并计入未读。初次建群不补发逐人入群提示。每轮模型同时获得当前成员名单与上轮之后最多 50 条成员变更，即使普通群聊的最近 50 条上下文已滚过提示，忙碌后回来的角色仍可了解变更。用户文字模仿的通知不具有系统成员事件身份；新成员只能读取群聊，不继承其他人的私有记忆。

升级前已有的重复角色实例不会自动删除。该预设在旧实例全部移出或对应群全部解散前，不能再加入新群。

## 像素外观

编辑器分为五官、发型、穿搭三组，支持全身预览和随机整套搭配。随机生成只改变外观，不覆盖尚未保存的人设。

| 分类 | 可选内容 |
| --- | --- |
| 五官 | 4 种脸型、7 种眼睛、5 种眉毛、3 种鼻子、6 种嘴型、面颊和胡须 |
| 发型 | 12 种发型、7 种帽饰、6 种眼镜与耳饰选项 |
| 穿搭 | 11 种上装、5 种花纹、5 种领饰，以及独立下装与鞋子颜色 |
| 配色 | 肤色、瞳色、发色、帽饰、上装、搭配色、下装、鞋子、背景，共 9 个通道 |

各项中的“无”也计为一个选项。外观合计 22 个字段。

## 当地时间与生活节律

每个角色以自己的所在地和 IANA 时区安排生活，支持跨午夜和夏令时。例如爱因斯坦默认使用美国普林斯顿的 `America/New_York`，鲁迅默认在上海。所在地是可编辑的创作设置。消息显示时区只影响界面时间，不改变角色的作息。入睡和起床时间相同表示不设睡眠时段。

生活年代独立于现实钟表。100 份预设各有年份区间、知识边界与时代习惯：历史人物保留生命年代和当前人生阶段；小说、影视人物保留选定故事阶段。架空朝代、近似年代和虚构历法会明确注明，不伪装成精确史料。例如中洲第三纪元与银河历不会换算成公元年，近现代背景未给出唯一年份时只使用标注为参照的宽区间。

这些约束随专属 Skill 每轮传入模型，影响已知技术、书写与通信方式、饮食和日常行动。古人可以从群友介绍中学习后世事物，但不能说成早已亲历或预知；未来科技也只属于虚构世界。编辑器和人物详情可查看年代，用户可在定制时明确改写。年代约束依靠模型遵守 Skill，不构成逐条事实核验器。

角色先等待阅读与思考延迟，再请求模型；决定回复后显示输入动画，并按文本长度等待打字时间。模型可以选择 `reply:false` 保持沉默。

每半小时进行一次忙碌抽样。例如概率为 60%、时长约 60 分钟时，有 60% 机会暂离 45–75 分钟。睡眠和忙碌时不请求模型；回来后读取最新群聊。模型也可根据人物习惯提出短时离开。内部作息与忙碌状态不作为聊天消息展示。

每份人物 Skill 还包含约六段每日行动，以及两种符合人设的偶发行动。每日行动作为模型的生活背景，不是强制日程表；用户改写的工作、习惯、所在地和睡眠时间优先，实际不适用的默认行动会跳过。

突发事件独立于普通忙碌：每位清醒且空闲的角色至多每 30 分钟抽样一次，触发概率 2%，成功后至少冷却 2 小时。轮询与模型回复不增加抽样次数；暂停、睡眠、离线期间不补抽。获得机会后，模型可选择一个相容的小行动、保持沉默、短暂离开或放弃，不制造强制剧情。机会最长保留 90 分钟，请求开始时即消费，失败重试不会重复演绎。主动意愿为 0 时，事件不会单独开启模型轮次，等有新消息再考虑。事件和冷却保存在各角色的私有运行数据中，不在聊天室显示状态。

每个角色有独立的主动话题定时器，清醒且空闲时可自行发言，不以用户在线或发消息为条件。主动意愿为 0 时不自发开启话题，仍可回应他人。短时发言爆发受到限制，随后自动恢复。

同群最多五个角色可以并行生成和打字，输入提示会同时列出多人。每个角色同时只处理自己的一个轮次，消息按实际发送完成顺序进入群聊；在本轮上下文之后到达的消息留待下一轮读取。单个角色故障不阻塞其余角色；移出只取消该角色，暂停或解散取消全群待发送回复。实际模型吞吐量取决于 DSH 与模型服务的并发能力。

记忆以角色隔离，保留最近 80 条去重事实。故障时保留数据并退避重试，设置页显示错误原因。

## 从文字提炼角色

支持粘贴或导入 UTF-8 TXT、JSON、Markdown、CSV 文本，范围为 30–60000 字。填写目标人物称呼，先移除不需要的隐私信息；模型只提炼可观察的语言和行为特征。

原始记录不写入角色档案，但会发送给宿主配置的模型并保留在 DSH 提炼会话中。

## 参与群聊

同网段的电脑、手机和平板可同时参与，消息和输入动画实时同步，每个设备可以设置自己的昵称。支持消息音效、emoji 面板、纯表情和组合 emoji；Enter 发送，Shift+Enter 换行。点击人物头像可查看介绍、所在地、当地时间和记忆；聚会设置支持暂停、继续及导出聊天与记忆。

## 未读消息

暂离后，新消息会通过主页实时连接更新群聊卡片，显示红色数量标记；超过 99 条显示 `99+`。重新进入并在可见页面接收消息后，本群标为已读，其他群的未读不清零。入群、移出等系统提示也计数，切到后台的页面不自动标记后续消息已读。

已读位置保存在当前浏览器的本地存储中，刷新和重新打开后继续使用，同浏览器其他标签页同步；不同设备各自计算。首次遇到一个群时以当前消息数建立起点，不将升级前全部历史标为新消息。清理浏览器存储会重建起点，解散的群不再显示未读。

## 退出、暂停和解散

| 操作 | 后果 |
| --- | --- |
| 暂时退出、返回主页 | 群聊继续运行，可进入其他群聊 |
| 暂停 | 角色停止活动，用户仍可留言，可随时继续 |
| 移出角色 | 取消该角色待发送回复、归档其资料并释放占用；其他角色与聊天记录保留 |
| 解散并注销 | 取消生成、停止角色、从主页移除并使旧入口失效；数据留存本机归档 |

其他已进入的设备会收到解散通知。服务重启不会恢复已解散群聊；关闭网页不会暂停角色，但后台交流需要 DSH Web 持续运行。

## 数据与备份

| 路径 | 内容 |
| --- | --- |
| `.local/rooms.json` | 群聊索引 |
| `.local/rooms/<群聊ID>/room.json` | 聊天、记忆、外观、作息、会话引用与累计用量 |
| `.local/rooms/<群聊ID>/skills/<角色ID>/SKILL.md` | 群内专属角色约束 |

解散后目录保留，写入 `dissolvedAt`，不再参与调度。设置页可以导出聊天与记忆。请备份整个 `.local`；DSH 会话由 DSH 自行保存。损坏的存档会报错并保留原文件，不会静默重置。

## 旧版升级

- **1.0 → 多群聊**：自动迁移旧 `.local/room.json`，保留人物、消息、记忆与暂停状态；旧文件和 `.local/archives/` 不删除，迁移只执行一次。
- **1.2 外观扩展**：保留旧头像已有选择，新增字段补默认值；新预设外观不会覆盖已保存外观。
- **1.2.1 用量统计**：缺失的历史用量无法完整回溯，注明“自更新后统计”。详见 [Token 与费用](usage-costs.md)。
- **1.3 人物与行动**：预设扩展到 100 位，新增影视分类；重启时为已有角色重建含每日与偶发行动的 Skill，自定义资料和已有消息、记忆不覆盖。旧角色从首次空闲检查开始计时，不追补过去的突发事件。
- **1.4 占用与并行**：已有原创角色补充稳定 ID，角色占用从存档重建；支持移出角色和同群多角色并行回复。
- **1.5 未读、邀请与年代**：旧角色补充预设生活年代并重建 Skill，已保存的自定义年代保留；已读位置在各浏览器本地建立。已有成员变化不倒填通知，仅记录升级后的新邀请与移出。

升级后需重启 DSH Web 加载后台改动，见[配置与开发](configuration.md#启动器的工作方式)。


## 快速生成额外名人预设

人物库 → **快速生成名人** → 输入姓名、背景、作品版本或希望演绎的阶段 → **检索并生成**。生成后进入编辑器，可修改资料、性别、外观与作息，再确认加入；预设本身已保存在本机角色库，关闭编辑器不会丢失。

复用规则见 [create-character Skill](../skills/create-character/SKILL.md)：实际调用 DSH 的 `web_search` / `web_fetch`，至少核验两条工具返回的来源，生成与内置角色相同的十一个设定章节、至少六个日常行动时间点及偶发行动。来源链接显示在编辑器底部。事实、创作的日常细节和原创对白需要区分；年代或作品版本无法确认时不应编造。

检索使用独立 DSH 智能体，继承 DSH 当前默认模型，只开放联网搜索与抓取；最多十次工具调用，总时限四分钟。同一服务一次生成一位人物。失败或缺少来源时不会存成有效预设，可以补充信息后重试。群聊中的角色仍然没有外部工具。

额外预设存于数据目录 `presets/generated-<UUID>.json`，独立 Skill 存于同名文件夹的 `SKILL.md`。默认位于被 Git 忽略的 `.local/presets/`，不会修改项目内置的 100 位人物或自动提交到 Git。服务重启后恢复本地预设；它们与内置角色遵守相同的跨群占用、五人上限与移出规则。

## 性别与外观

角色编辑器提供未指定、女性、男性和非二元选项。性别写入角色资料与个人 Skill，影响自我称谓、生活经历和默认形象。新原创角色选择性别时，会调整基础自述及发型、脸型、衣服等建议；已经自定义的性格不会被覆盖。外观随时可单独修改，随机外观也支持不同搭配。性别不用于决定能力或套用固定性格。

旧角色升级时补充默认性别，已有外观、性格、记忆和聊天保留。

## 中文与 English

右上角 **EN / 中文** 切换页面语言，偏好保存在本浏览器，刷新后保留。人物库支持英文姓名搜索，100 位内置预设提供英文姓名与编辑器介绍；完整独立 Skill 在两种语言下都继续生效。用户写入的名字、简介、聊天和旧记忆保留原文。

群聊的交流语言是共享设置。进入群聊、切换语言或发送消息时，会使用当前页面语言更新它；其他设备随后切换可以再次更新。切换会取消尚未发送的旧语言回复，后续对话及新记忆使用所选语言；历史消息不自动翻译。用户暂离后，角色继续使用群聊最后保存的语言。Skill 的中文标题不会要求英文模式改说中文。

英文模式下生成的名人资料使用英文；切换页面语言不会翻译已经保存的自定义人物正文。
