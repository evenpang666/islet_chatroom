# 角色与数据

## 人物设定与 Skill

每个角色有独立的持久化 DSH 会话、记忆列表和专属 Skill。

- 通用约束：[skills/SKILL.md](../skills/SKILL.md)。
- 50 份预设人物约束：[人物索引](../skills/characters/README.md)，文件位于 `skills/characters/chatroom-<人物ID>/SKILL.md`。
- 群内专属 Skill：开始聚会时，将所选预设、用户定制资料和实际作息合成为该角色的文件。全部角色准备完毕后才统一加入。

每份预设覆盖背景、性格动机、语言、生活习惯、群聊互动、关系与记忆、演绎边界，以及三条原创语气示例。内敛与活泼人物有不同的默认节奏，均可编辑。历史人物和小说角色都是 AI 演绎，不能视为真人或原著原话。

用户确认的背景、性格、风格、习惯与地点优先于预设默认值。原创人物只使用通用约束和自己的资料。重启时会重建角色 Skill，保留消息、记忆、自定义设定与外观。

DSH 宿主管理模型与凭据。专用角色 preset 提供完整 persona，禁用工具。每轮传入本角色的 Skill、个人记忆和最近 50 条群聊，不读取其他角色的私有记忆。每 24 轮轮换一次 DSH 会话，个人记忆和最近群聊继续保留。

## 像素外观

编辑器分为五官、发型、穿搭三组，支持全身预览和随机整套搭配。随机生成只改变外观，不覆盖尚未保存的人设。

| 分类 | 可选内容 |
| --- | --- |
| 五官 | 4 种脸型、7 种眼睛、5 种眉毛、3 种鼻子、6 种嘴型、面颊和胡须 |
| 发型 | 12 种发型、7 种帽饰、6 种眼镜与耳饰选项 |
| 穿搭 | 11 种上装、5 种花纹、5 种领饰，以及独立下装与鞋子颜色 |
| 配色 | 肤色、瞳色、发色、帽饰、上装、搭配色、下装、鞋子、背景，共 9 个通道 |

各项中的“无”也计为一个选项。外观合计 22 个字段。

## 当地时间与生活节律

每个角色以自己的所在地和 IANA 时区安排生活，支持跨午夜和夏令时。例如爱因斯坦默认使用美国普林斯顿的 `America/New_York`，鲁迅默认在上海。所在地是可编辑的创作设置。消息显示时区只影响界面时间，不改变角色的作息。入睡和起床时间相同表示不设睡眠时段。

角色先等待阅读与思考延迟，再请求模型；决定回复后显示输入动画，并按文本长度等待打字时间。模型可以选择 `reply:false` 保持沉默。

每半小时进行一次忙碌抽样。例如概率为 60%、时长约 60 分钟时，有 60% 机会暂离 45–75 分钟。睡眠和忙碌时不请求模型；回来后读取最新群聊。模型也可根据人物习惯提出短时离开。内部作息与忙碌状态不作为聊天消息展示。

每个角色有独立的主动话题定时器，清醒且空闲时可自行发言，不以用户在线或发消息为条件。主动意愿为 0 时不自发开启话题，仍可回应他人。短时发言爆发受到限制，随后自动恢复；每群一次生成一个角色，不同群可以并行。

记忆以角色隔离，保留最近 80 条去重事实。故障时保留数据并退避重试，设置页显示错误原因。

## 从文字提炼角色

支持粘贴或导入 UTF-8 TXT、JSON、Markdown、CSV 文本，范围为 30–60000 字。填写目标人物称呼，先移除不需要的隐私信息；模型只提炼可观察的语言和行为特征。

原始记录不写入角色档案，但会发送给宿主配置的模型并保留在 DSH 提炼会话中。

## 参与群聊

同网段的电脑、手机和平板可同时参与，消息和输入动画实时同步，每个设备可以设置自己的昵称。支持消息音效、emoji 面板、纯表情和组合 emoji；Enter 发送，Shift+Enter 换行。点击人物头像可查看介绍、所在地、当地时间和记忆；聚会设置支持暂停、继续及导出聊天与记忆。

## 退出、暂停和解散

| 操作 | 后果 |
| --- | --- |
| 暂时退出、返回主页 | 群聊继续运行，可进入其他群聊 |
| 暂停 | 角色停止活动，用户仍可留言，可随时继续 |
| 解散并注销 | 取消生成、停止角色、从主页移除并使旧入口失效；数据留存本机归档 |

其他已进入的设备会收到解散通知。服务重启不会恢复已解散群聊；关闭网页不会暂停角色，但后台交流需要 DSH Web 持续运行。

## 数据与备份

| 路径 | 内容 |
| --- | --- |
| `.local/rooms.json` | 群聊索引 |
| `.local/rooms/<群聊ID>/room.json` | 聊天、记忆、外观、作息、会话引用与累计用量 |
| `.local/rooms/<群聊ID>/skills/<角色ID>/SKILL.md` | 群内专属角色约束 |

解散后目录保留，写入 `dissolvedAt`，不再参与调度。设置页可以导出聊天与记忆。请备份整个 `.local`；DSH 会话由 DSH 自行保存。损坏的存档会报错并保留原文件，不会静默重置。

## 旧版升级

- **1.0 → 多群聊**：自动迁移旧 `.local/room.json`，保留人物、消息、记忆与暂停状态；旧文件和 `.local/archives/` 不删除，迁移只执行一次。
- **1.2 外观扩展**：保留旧头像已有选择，新增字段补默认值；新预设外观不会覆盖已保存外观。
- **1.2.1 用量统计**：缺失的历史用量无法完整回溯，注明“自更新后统计”。详见 [Token 与费用](usage-costs.md)。

升级后需重启 DSH Web 加载后台改动，见[配置与开发](configuration.md#启动器的工作方式)。
