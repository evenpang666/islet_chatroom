# Token 与费用

[返回项目首页](../README.md) · [全部文档](README.md)

每个聊天室最下方以小字显示本群累计的估算 Token 和费用，实时更新，退出再进入及服务重启后保留。鼠标悬停可查看输入、输出与估算说明。

![页脚用量显示，图中为界面测试数据](screenshots/room-usage.png)

## 统计范围

计入本群所有角色的主动发言、沉默判断、格式重试，以及已经产生用量的失败或取消请求。创建群聊前的文本角色提炼不归入任何聊天室；不同群聊相互独立。

优先使用 DSH 返回的输入、输出、缓存读取和缓存写入用量。推理 Token 已包含在输出中，不重复相加；缺少用量时按文本长度粗估。模型在对话 JSON 中自行声称的 usage 不用于计量。

旧群聊缺失的历史用量无法完整回溯，会注明“自更新后统计”。计量功能需要重启 DSH Web 加载 1.2.1 或后续版本后生效。

## 减少重复上下文

角色会话首次发送完整通用 Skill、个人 Skill 和预算内的群聊、记忆；后续只追加未发送的消息、记忆变化和必要的成员名单更新。固定设定不反复追加到会话历史。角色设定或语言变化、近期消息出现缺口、DSH Web 手动修改会话或宿主压缩后，会重新建立上下文。

| 内容 | 默认预算或行为 |
| --- | --- |
| 近期群聊 | 最多 50 条，约 4096 Token；单条过长时标注并提供末尾片段 |
| 个人记忆 | 约 2048 Token；结合近期聊天的本地关键词匹配和新近程度选择，不新增模型调用 |
| 成员变更通知 | 约 1024 Token；和群聊中的同一通知去重 |
| 会话轮换 | 约 32768 Token 的上下文阈值，或累计 24 次请求；格式修复也计数 |
| 角色输出 | 最多 4096 Token，包含模型推理；用户已设置更低上限时保持较低值 |

预算使用本项目的文本估算器，不是模型的精确 tokenizer。完整 Skill 不截断，超长设定会相应提高该会话的轮换阈值；读取到宿主模型窗口时，还会为输出预留空间并收紧阈值。生成失败的会话下次直接重建，格式修复也受请求数与上下文预算限制，过长的无效输出不会再次整段回传修复。

筛选只影响本次模型输入；原始群聊、完整 Skill 和原有持久记忆继续保存。每次重建会从当前数据重新选择记忆和近期聊天，旧记忆可以随话题相关性重新进入上下文。后端重启后首次生成会重建一次上下文，之后恢复增量发送。

24 轮固定模拟回放的累计估算输入由 2,139,080 降至 267,194 Token，减少约 87.5%。该数字用于检验重复输入的减少，不是实际模型用量或账单节省比例；真实费用还取决于缓存命中、模型与对话长度。

## 费用估算

默认包含 `deepseek-official` 的 Flash / V4 Pro 路由，按 [DeepSeek 官方公开高峰单价](https://api-docs.deepseek.com/quick_start/pricing/)保守估算，核对日期为 **2026-10-18**，单位为美元/百万 Token。

估算不模拟低峰折扣、优惠或账户账单。没有单价的路由显示“待配置单价”；部分请求无法计价时会注明。混用不同币种分别显示，不隐式换汇。

费用逐次累计保存。后续修改单价不会重新计算已经保存的费用。

## 自定义单价

在启动前设置 `CHATROOM_TOKEN_PRICES`，内容为 JSON 对象，键为精确的 `provider/model` 路由：

```json
{
  "my-provider/my-model": {
    "input": 1,
    "output": 2,
    "cacheRead": 0.1,
    "cacheWrite": 1,
    "currency": "USD"
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `input` | 非缓存输入单价，必填 |
| `output` | 输出单价，必填 |
| `cacheRead` | 缓存读取单价，省略时使用输入单价 |
| `cacheWrite` | 缓存写入单价，省略时使用输入单价 |
| `currency` | `USD`、`CNY` 或 `EUR`，必填 |

所有单价均为**每百万 Token**的非负金额。配置后重启服务；自定义项可以覆盖同一路由的内置单价。

名人预设检索属于共享角色库的创建过程，不计入任一聊天室的累计用量；仍会使用 DSH 模型和联网服务，相关实际费用以宿主与提供商记录为准。
